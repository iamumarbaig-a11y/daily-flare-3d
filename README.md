# Daily Flare 3D

Native Android map-animation studio for Daily Flare.

## Direction

- Native Android, not a web wrapper
- Kotlin + Jetpack Compose
- MapLibre Native for the map renderer
- Timeline-driven animation engine
- Camera, route, country highlight, marker, flag and label animation
- Deterministic 30/60 FPS export pipeline
- Designed for personal/offline-first use where practical

## Reference

AnimateMyMap is being used as a functional reference for the feature set and workflow. Daily Flare 3D will use an independent implementation and its own UI/assets.

## Current milestone

Milestone 1 establishes the native Android project, MapLibre renderer, Compose shell and animation-studio architecture. Feature work will be added incrementally after the baseline build is verified.
